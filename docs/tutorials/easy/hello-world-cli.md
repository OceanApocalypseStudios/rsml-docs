# 'Hello, World!' on the CLI Walkthrough
:::tip

It's recommended to follow the ['Hello, World!' walkthrough](hello-world) first if you're planning on using RSML programmatically via its APIs or native exports.

:::

The CLI can be a great tool for quick testing and evaluating, but also an extremely powerful tool used for automation.

Upon completing this walkthrough, you'll learn how to use the very basics of RSML's CLI: we won't touch on the advanced parts.

## Requirements
- **[RSML's CLI](https://github.com/OceanApocalypse/RedSeaModernLanguage/releases/latest)**
